# Format Wheel — приложение

Код программы Format Wheel (версия 1.0.5) и SDK для расширений. Общее описание и список расширений — в [главном репозитории](https://github.com/KantraCity/FormatWheel).

Требования: Windows 10 (1809) или 11, x64. Установщик ставит программу для текущего пользователя в `%LOCALAPPDATA%\Programs\FormatWheel`, права администратора не нужны.

## Структура

```
src/
├── FormatWheel.Sdk/      контракт для расширений (IConverter, WheelSlot, WheelOption, Recipe, OutputPath) → .nupkg
└── FormatWheel/
    ├── Core/             контроллер колеса, реестр и загрузчик расширений, рецепт, журнал, автозапуск,
    │                     папка копий и её очистка (Paths), облегчённый режим (Perf)
    ├── Imaging/          встроенный конвертер картинок (Magick.NET), форматы, размеры, HEIC, миниатюры
    ├── Interop/          WinAPI, хук клавиатуры, поиск папки под курсором (ShellTarget)
    ├── Localization/     строки интерфейса (ru, en)
    └── UI/               колесо, превью у курсора, кольцо прогресса, меню трея
installer/                скрипт Inno Setup
```

## Сборка

Нужны Windows 10/11 и [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet run --project src/FormatWheel
```

Установщик целиком (нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php) — если его нет, скрипт поставит через winget; заодно пакует SDK в `dist/`):

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Только пакет SDK:

```powershell
dotnet pack src/FormatWheel.Sdk -c Release -o dist
```

GitHub Actions собирает то же самое по тегу `v*`: в релиз попадают установщик `FormatWheel-Setup-x.y.z.exe` и `FormatWheel.Sdk.x.y.z.nupkg`. Если в секретах репозитория задан `NUGET_API_KEY`, пакет SDK дополнительно публикуется на nuget.org; пока он там не опубликован, расширения подключают `.nupkg` из релиза как локальный источник пакетов.

## Как устроена «пересадка» драга

Пока вы тянете файл, драг принадлежит Проводнику, и подменить его данные снаружи нельзя. Поэтому:

1. Под курсором появляется почти прозрачное окно. Проводник сам сообщает ему путь к файлу через `DragEnter`.
2. При выборе формата программа отменяет драг Проводника (эмулирует Esc).
3. Под курсор ставится крошечная невидимая «ловушка», и имитируется «отпустить + нажать» мышь. Кнопку вы держите, но нажатие теперь числится за нашим окном.
4. Запускается свой `DoDragDrop`. Пока идёт конвертация, получателю не предлагается ничего; как только копия готова в `%TEMP%\FormatWheel`, драг начинает предлагать файл, а окно под курсором получает повторный `DragOver`, чтобы получатель сразу показал, что примет его.
5. Если бросили раньше, чем файл готов (или бросили в папку, а Проводник так и не взял готовый файл), конвертация доводится до конца, и результат сохраняется в папку, куда его бросили (окно Проводника или рабочий стол — `ShellTarget`), иначе рядом с оригиналом. Об этом приходит уведомление.

## Клавиши

Shift открывает колесо, Ctrl и Alt при зажатом Shift переключают слот (`Primary`, `Ctrl`, `Alt`, `CtrlAlt`). Нажатие засчитывается через 60 мс, чтобы случайное касание не дёргало меню. Отпускание Ctrl/Alt раньше Shift меню не меняет: переключение происходит, только если Shift держат ещё ~0.6 с или мышь сдвинулась на 24 px.

## Папка копий

Сконвертированные файлы лежат в `%TEMP%\FormatWheel`. При запуске и раз в час программа удаляет из неё всё старше суток и самые старые файлы сверх 2 ГБ. Файлы моложе 10 минут не трогаются никогда — получатель мог ещё не забрать их. Там же лежит журнал `log.txt`.

## Меню в трее

Автозапуск с Windows, открыть папку с копиями, открыть журнал, список расширений, открыть папку расширений, перезагрузить расширения, выход.

## Расширения

Приложение грузит DLL с именем `FormatWheel.*` из подпапок:
- `<папка программы>\extensions\` (`%LOCALAPPDATA%\Programs\FormatWheel\extensions\`) — сюда ставят установщики расширений, доверенные. Эту папку открывает пункт трея «Расширения → Открыть папку расширений»;
- `%APPDATA%\FormatWheel\extensions\` — расширения, положенные вручную, включаются после подтверждения; при изменении DLL подтверждение запрашивается заново.

Как написать расширение — в README главного репозитория.

## Переменные окружения

- `FORMATWHEEL_LANG=xx` — язык интерфейса без смены языка системы.
- `FORMATWHEEL_LITE=1` / `0` — принудительно включить или выключить облегчённый режим (анимации 30 кадров/с, без пружин и поворотов). Сам он включается, если видеокарта не тянет WPF полностью или ядер 4 и меньше.

## Локализация

Язык берётся из системы (`ru` / `en`). Чтобы добавить язык: скопировать `Strings.en.cs` в `Strings.xx.cs`, перевести, добавить строчку в `Loc.S`.
