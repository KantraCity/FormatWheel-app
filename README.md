# Format Wheel — приложение

Код программы Format Wheel и SDK для расширений. Общее описание и список расширений — в [главном репозитории](https://github.com/KantraCity/FormatWheel).

## Структура

```
src/
├── FormatWheel.Sdk/      контракт для расширений (IConverter, WheelSlot, WheelOption, Recipe) → NuGet-пакет
└── FormatWheel/
    ├── Core/             контроллер, реестр и загрузчик расширений, рецепт, журнал, автозапуск
    ├── Imaging/          встроенный конвертер картинок (Magick.NET), размеры, HEIC, миниатюры
    ├── Interop/          WinAPI, хук клавиатуры
    ├── Localization/     строки интерфейса (ru, en)
    └── UI/               колесо, превью у курсора, кольцо прогресса
```

## Сборка

Нужны Windows 10/11 и [.NET 10 SDK](https://dotnet.microsoft.com/download).

```powershell
dotnet run --project src/FormatWheel
```

Установщик целиком (заодно пакует SDK в `dist/`):

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

## Как устроена «пересадка» драга

Пока вы тянете файл, драг принадлежит Проводнику, и подменить его данные снаружи нельзя. Поэтому:

1. Под курсором появляется почти прозрачное окно. Проводник сам сообщает ему путь к файлу через `DragEnter`.
2. При выборе формата программа отменяет драг Проводника (эмулирует Esc).
3. Под курсор ставится крошечная невидимая «ловушка», и имитируется «отпустить + нажать» мышь. Кнопку вы держите, но нажатие теперь числится за нашим окном.
4. Запускается свой `DoDragDrop`, который отдаёт получателю не файл, а «обещание» файла. Сконвертированная копия кладётся в `%TEMP%\FormatWheel` и отдаётся в момент броска.

## Расширения

Приложение грузит DLL с именем `FormatWheel.*` из папок:
- `<папка программы>\extensions\` (`%LOCALAPPDATA%\Programs\FormatWheel\extensions\`) — сюда ставят установщики расширений, доверенные. Эту папку открывает пункт трея «Расширения → Открыть папку расширений»;
- `%APPDATA%\FormatWheel\extensions\` — расширения, положенные вручную, включаются после подтверждения.

Как написать расширение — в README главного репозитория. SDK публикуется как NuGet-пакет `FormatWheel.Sdk`.

## Локализация

Язык берётся из системы (`ru` / `en`). Чтобы добавить язык: скопировать `Strings.en.cs` в `Strings.xx.cs`, перевести, добавить строчку в `Loc.S`. Проверить, не меняя язык системы: переменная `FORMATWHEEL_LANG=xx`.
